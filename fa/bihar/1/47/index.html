علامه محمدباقر مجلسی 1 47

الشيخ لم نعين لها رمزا و كذا أمالي ولد الشيخ شركناه مع أمالي والده في الرمز لأن جميع أخباره إنما يرويها عن والده رضي اللّٰه عنهما.

شیخ رمزی معین نکردیم؛ و همچنین امالی فرزند شیخ را با امالی پدرش در رمز شریک ساختیم، چرا که همهٔ اخبارش را از پدرش روایت می‌کند، رضی الله عنهما.

مل لكامل الزيارة سن للمحاسن فس لتفسير علي بن إبراهيم شي لتفسير العياشي م لتفسير الإمام عليه السلام ضه لروضة الواعظين عم لإعلام الوري مكا لمكارم الأخلاق ج للإحتجاج قب لمناقب ابن شهرآشوب كشف لكشف الغمة ف لتحف العقول مد للعمدة نص للكفاية نبه لتنبيه الخاطر نهج لنهج البلاغة طب لطب الأئمة صح لصحيفة الرضا عليه السلام ضا لفقه الرضا عليه السلام يج للخرائج ص لقصص الأنبياء ضوء لضوء الشهاب طا لأمان الأخطار شف لكشف اليقين.

«مل» برای کامل الزیارة؛ «سن» برای المحاسن؛ «فس» برای تفسیر علی بن ابراهیم؛ «شی» برای تفسیر عیاشی؛ «م» برای تفسیر امام علیه السلام؛ «ضه» برای روضة الواعظین؛ «عم» برای إعلام الوری؛ «مکا» برای مکارم الأخلاق؛ «ج» برای الاحتجاج؛ «قب» برای مناقب ابن شهرآشوب؛ «کشف» برای کشف الغمة؛ «ف» برای تحف العقول؛ «مد» برای العمدة؛ «نص» برای الکفایة؛ «نبه» برای تنبیه الخاطر؛ «نهج» برای نهج البلاغة؛ «طب» برای طب الأئمة؛ «صح» برای صحیفهٔ رضا علیه السلام؛ «ضا» برای فقه الرضا علیه السلام؛ «یج» برای الخرائج؛ «ص» برای قصص الأنبیاء؛ «ضوء» برای ضوء الشهاب؛ «طا» برای أمان الأخطار؛ «شف» برای کشف الیقین.

«یف» برای الطرائف؛ «قیه» برای الدروع؛ «فتح» برای فتح الأبواب؛ «نجم» برای کتاب النجوم؛ «جم» برای جمال الأسبوع؛ «قل» برای إقبال الأعمال؛ «تم» برای فلاح السائل، چون از تتمه‌های المصباح است؛ «مهج» برای مهج الدعوات؛ «صبا» برای مصباح الزائر؛ «حة» برای فرحة الغری؛ «کنز» برای کنز جامع الفوائد و تأویل الآیات الظاهرة با هم، چون یکی از دیگری گرفته شده، چنان‌که دانستی؛ «غو» برای غوالی اللآلی — و النثر به رمز نیازی ندارد؛ «جع» برای جامع الأخبار؛ «نی» برای غیبت نعمانی؛ «فض» برای کتاب الروضة، چون در فضائل است؛ «مص» برای مصباح الشریعة؛ «قبس» برای قبس المصباح؛ «ط» برای الصراط المستقیم؛ «خص» برای منتخب البصائر؛ «سر» برای السرائر؛ «ق» برای الکتاب العتیق الغروی؛ «کش» برای رجال کشی؛ «جش» برای فهرست نجاشی؛ «بشا» برای بشارة المصطفی؛ «ین» برای دو کتاب حسین بن سعید، یا برای کتاب او و النوادر؛ «عین» برای العیون و المحاسن؛ «غر» برای الغرر و الدرر؛ «کف» برای مصباح کفعمی؛ «لد» برای البلد الأمین؛ «قضا» برای قضاء الحقوق؛ «محص» برای التمحیص؛ «عدة» برای العدة؛ «جنة» برای الجنة؛ «منها» برای المنهاج؛ «د» برای العدد؛ «یل» برای الفضائل؛ «فر» برای تفسیر فرات بن ابراهیم؛ «عا» برای دعائم الإسلام.
